New
- Unread line: when a chat has new texts, it opens at the first new one with a slim "Unread messages" line above it, like Google Messages and WhatsApp. The line stays while the chat is open and is gone the next time you open it
- "↓ 3 new" button: if texts come in while you're reading higher up, a button shows how many; tap it to jump down

Fixed
- Keyboard no longer squashes the chat: the top bar (back arrow, name, picture) stays at the top, the messages get shorter, and the typing box sits right on top of the keyboard, like Google Messages
- Opening a chat or group no longer pops up the keyboard. It comes up only when you tap the typing box (a brand-new conversation still opens ready to type)
- A chat opens right where it should, with no scrolling down: at the first new text, or already at the bottom if there's nothing new
- When the keyboard opens while you're at the bottom, the newest message stays in view
- Photos loading in the chat no longer push the newest messages down

New
- Google's own font: the whole app now uses Google Sans (Google Sans Flex), the font Google Messages uses, instead of Rubik
- Yiddish / Hebrew letters (incl. ײ, װ, ױ, ײַ and nikud) are built into the same font at the same weight, so Yiddish looks clean and matches the English text
- Google Messages text sizes: "Messages" title 24sp, names 16sp (bold when unread), previews 14sp, times 12sp
- Settings > Theme: the font switch is now "Google Sans font" (off = your phone's font)

Fixed
- Read chats' names now use the medium weight like Google Messages, so unread (bold) stands out clearly
- Smaller app fonts: 4 compact font files replace the old Rubik ones

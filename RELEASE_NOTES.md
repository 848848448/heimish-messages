New
- Chat list redesigned to match Google Messages: a tinted top bar with a bigger "Messages" title, and the list sits on a rounded sheet
- Photos, voice messages, videos and attachments in the chat list now show a small Google icon instead of an emoji (📷 / 🎤 are gone)
- Unread chats: bold name and preview, the time turns blue, and a blue count badge (or a dot for one message)
- Placeholder avatars show the contact's first letter on a colored circle; the person icon is only for numbers without a name
- Cleaner rows: 52dp avatars (48dp on small screens), 16sp names, 14sp previews, tidier spacing
- Filter chips, the Start chat button and the account button restyled the Google Messages way (rounded-square Start chat button)
- Chat screen: the message area, compose bar and header use the same tinted Google Messages colors; the compose field stands out more
- Settings pages: rounded cards on a tinted background, like Google Messages settings

Fixed
- Long Yiddish / Hebrew names (and group names) no longer lose their first letter, and the "…" lands at the right end of the name
- Contacts whose name starts with an invisible character or a symbol now get their letter avatar instead of a person icon
- Better fit on small, low-resolution screens

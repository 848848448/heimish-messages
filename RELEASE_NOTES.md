New
- Swipe a message to reply: the reply now shows the quoted message on top of your sent bubble too (not only while typing). Tap the quote to jump to the original message
- Reactions: press and hold a message → 👍 ❤️ 😂 😮 😢 🙏 or + for any emoji. People without this app get the normal text ("Liked “…”"), like Google Messages and iPhone do. You can turn that off in Settings → Chat features
- Reactions from iPhones and Google Messages ("Liked “…”", "Loved “…”", "Laughed at “…”", "Reacted 🔥 to “…”") now show as a small reaction on that message instead of a separate text. Tap the reaction to see who sent it
- Schedule send: type a message, then press and hold Send to pick a time. Photos and videos can be scheduled too
- Scheduled messages: tap one in the chat (or in Scheduled messages on the main menu) to send it now, edit the text, change the time or delete it
- "Copy code" button under one-time codes and verification codes, and in their notification. One tap copies it
- Remind me on a message: press and hold a message → Remind me → pick a time. The reminder opens the chat right at that message, with Snooze 1 hour and Done buttons
- Search in a chat: every match is highlighted, and the arrows go to the next or previous match
- Starred messages: tap one to open the chat right at that message
- Backup & restore now saves everything: texts AND picture messages with their photos, videos and voice notes, in one .zip file. Restore puts back only what's missing
- Automatic backup: daily or weekly into a folder you pick. It keeps the newest 5 backups and deletes older ones
- Settings → Chat features: reactions as text, iPhone reactions, smart replies, Copy code button

Fixed
- Scheduled messages could disappear after a phone restart when two were set at the same time, and an app update could cancel them. Now they're set again after every restart and update and still go out on time
- "Edit" on a scheduled message lost the message if you had already typed something. It now edits it in place
- A scheduled message that fails to send now shows a "not sent" notification instead of disappearing silently
- Reminders used to open nothing. They now open the chat at the message
- "Copy code" no longer picks up phone numbers, prices or order numbers as codes
- Old backups (.json) still restore

New
- Chat menu (⋮) is short now: Search, Details, Schedule send, Mute, More. "More" opens a sheet with the rest (chat theme, media and links, quick replies, remind me, label, notification sound, export, add to home screen, block, delete)
- The version now shows the build number, e.g. "Version 3.6.257"
- Auto-reply has an "Only to my contacts" switch, on by default, so unknown numbers and spammers don't get an answer

Fixed
- Reactions (👍 ❤️ …) are no longer sent as a text message by default. In groups that used to text everyone. You can turn it back on in Settings
- A scheduled message that fails to send is no longer lost. It retries by itself (after 1, 5 and 15 minutes, then 1 hour). If it still can't send, it stays under Scheduled marked "Not sent", so you can change it or send it again
- The character counter above the keyboard now counts SMS parts correctly for accents, special symbols, emoji and Hebrew
- Search filters (Images, Videos, Starred, Links, Places) show "No results" instead of spinning forever when nothing is found
- A picture message waiting for signal during a long outage is no longer thrown away after an hour
- After an update the app no longer tries to open itself (Android blocks that), and the update check and nightly contacts sync are switched back on right away
- The photo strip above the keyboard loads only the newest photos, not every photo on the phone, so it opens faster
- Update notes show up even when GitHub is busy
- Old temporary files (camera photos, voice recordings, keyboard GIFs) are cleaned up after 2 days
- Auto-delete of old codes now only removes real code messages, not every text with a 4-digit number like a year

New
- Admin panel → Contact search is redesigned like Google Messages: each result is a clean row with a coloured letter avatar, the name in bold and the number neatly formatted, e.g. (845) 238-9140
- Every result has buttons to text, copy and call. Tap a row to open the chat right away; long-press a row to copy the number ("Copied" pops up)
- Search starts by itself while you type, with a spinner while it loads, the best name matches on top and the matching letters highlighted
- Shows how many results were found, a clear "No results" screen, and a "Try again" button when the search fails

Fixed
- Hebrew/Yiddish names and numbers no longer get mixed up and flipped on the same line
- The same number from several phones, or saved in different formats, now shows only once
- The ugly phone id after each contact is gone (a small tag shows only when contacts come from more than one phone)
- Going into a chat from contact search and coming back keeps your search and results
